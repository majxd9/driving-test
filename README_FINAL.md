# رخصتي — Driving Test Final

نسخة موحّدة ومحسّنة من المشروع، تجمع واجهة وإدارة الإصدار المتقدم مع حفظ محاولات الاختبار والتحسينات الموجودة في النسخة اللاحقة.

## أهم ما تم تحسينه

- **٨ نماذج اختبار** بدل ٦، والنموذجان ٧ و٨ بمستوى تحدٍ متقدم.
- كل نموذج يجهّز **٣٠ سؤالاً بالضبط** (١٢ سير + ١٢ إشارات + ٦ ميكانيك) باستخدام اختيار deterministic، بعد إصلاح خوارزمية كانت قد تنتج ٢٨/٢٩ سؤالاً.
- حفظ كل محاولة اختبار في `ExamAttempts` مع عدد الإجابات الصحيحة والخاطئة والأسئلة التي أخطأ بها الطالب.
- لوحة الإدارة تحتفظ بإدارة الطلاب والأسئلة والرسوم والتحليلات، وتعرض إحصاءات محاولات الطلاب.
- شاشة النتيجة تعرض الأسئلة الخاطئة وشرح الإجابة.
- تسجيل الدخول يحتوي على زر **تجربة عينة مجانية من ٥ أسئلة قوية** بدون الحاجة لتسجيل الدخول.
- تم دمج أفضل مكوّنات الواجهة: التحميل الكسول، صور محسّنة، skeletons، preloading للأسئلة القريبة، ورسوم التوضيح.
- تم إدخال صور `Traffic_Signals_Images` المرفقة ضمن `client/public/signs`، وتحديث الأسئلة التي لها صورة متوفرة إلى ملفات PNG المرفقة.
- ترقية قاعدة البيانات القديمة تتم بشكل idempotent، مع إنشاء `ExamAttempts` وإضافة حقول الـ Diagram دون حذف البيانات الموجودة.
- حماية حفظ النتائج: الـ API يأخذ هوية الطالب من JWT ولا يستقبل `StudentId` من الواجهة.
- لا توجد أسرار أو كلمات مرور ثابتة داخل الكود.

## بنية المشروع

- `client/` — React + TypeScript + Vite + Tailwind
- `server/` — ASP.NET Core 8 + PostgreSQL + Identity + JWT Cookie
- `server/Data/SeedData/questions.json` — بنك الأسئلة (٣٩٧ سؤالاً)

## متغيرات البيئة

- `ConnectionStrings__DefaultConnection`
- `Jwt__Key`
- `Jwt__Issuer` (اختياري)
- `FrontendOrigin`
- `SeedAdmin__UserName`
- `SeedAdmin__Password`

## التشغيل

### Client

```bash
cd client
npm install
npm run build
npm run dev
```

### Server

```bash
cd server
dotnet restore
dotnet run
```

إذا كانت قاعدة PostgreSQL قديمة، يقوم `DbSeeder` بترقية الجداول اللازمة عند الإقلاع بشكل آمن دون حذف البيانات.

## ملاحظة مهمة

بيئة التنفيذ الحالية لا تحتوي على .NET SDK، كما أن تثبيت حزم npm الخارجية لم يكتمل بسبب عدم توفر الحزم المطلوبة في cache. لذلك تم إجراء فحوصات ساكنة على الملفات وبيانات الأسئلة والمسارات والصور، لكن **لم يكن ممكناً تنفيذ build فعلي للـ .NET، ولم يكتمل build للـ client بسبب نقص dependencies**.
