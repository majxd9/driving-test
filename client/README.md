# الواجهة الأمامية — React + Vite

## التشغيل محلياً
```bash
npm install
npm run dev
```
بيفتح على http://localhost:5173 ويتوجه تلقائياً لـ API على http://localhost:5000 (عدّل الـ proxy بـ vite.config.ts إذا الباك إند شغال على بورت مختلف).

## قبل الرفع (Build)
```bash
npm run build
```
بينتج مجلد `dist/` جاهز يترفع على Netlify مباشرة.

## متغير مهم عند النشر
لازم تحدد رابط الـ Backend الحقيقي عبر متغير بيئة `VITE_API_URL` (مثلاً رابط خدمتك على Render) عند البناء للإنتاج، وإلا رح يحاول يتواصل مع نفس النطاق.

## نظام الألوان
كل الألوان معرّفة بمكان واحد: `tailwind.config.js` — تغيير أي لون هناك بينعكس على كل الواجهة فوراً. الألوان الحالية غامقة (asphalt/night) بناء على طلبك، وكل قسم إله لون ثابت (سير=أخضر، إشارات=أزرق، ميكانيك=نحاسي، اختبار=أحمر).

## ملاحظة
صفحة الاختبار (Exam) حالياً بتسحب ٣٠ سؤال بشكل موزّع من الفئات الثلاث لكل نموذج، لأنه الـ Backend لسا ما عنده Endpoint مخصص للنماذج الستة الرسمية بالضبط — هاي نقطة نكملها بمرحلة ربط قاعدة البيانات.
