# مستكشف Dodge Challenger 1970 — ملف النموذج مطلوب

هذه الصفحة معزولة عن محاكي الإضاءة وتُحمّل فقط عند فتح المسار `/car-viewer`.

قبل دمج هذا الفرع أو نشره، يجب إضافة الملف الثنائي الناتج من ملف Blender الأصلي إلى:

`client/public/car-explorer/assets/challenger-1970.glb`

الملف المضغوط `challenger-1970-explorer.zip` الذي جهّزناه محلياً يحتوي على هذا الملف. لم يُرفع الملف الثنائي إلى هذا الفرع، لأن واجهة GitHub المتاحة هنا تسمح بإنشاء/تعديل ملفات نصية ولا توفر رفع ملف محلي كبير مباشرة. لذلك أبقيت التغييرات بفرع منفصل/مسودة كي لا يظهر رابط غير مكتمل للمستخدمين أو يتأثر `main`.

لا تضف أي بديل أو مجسّم آخر مكان هذا الملف. بعد وضع GLB الصحيح، اختبر `npm run build` ثم افتح المعاينة على هاتف فعلي قبل دمج الفرع.
