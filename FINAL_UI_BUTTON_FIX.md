# UI Button & Layout Fix

- Exam question title has a reserved fixed-height area so different question lengths do not move the answer controls around.
- Previous/next controls use a stable height and stay anchored at the bottom of the exam question card.
- Mobile breakpoint increases answer-button and navigation-button touch targets.
- Study mode reuses the same stable answer/navigation layout.
- Removed the admin-device availability message from the login screen; it was implementation detail and not useful to students.
