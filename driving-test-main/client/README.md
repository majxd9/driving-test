# رخصتي — Frontend

## ما تم تطويره
- إعادة تصميم كاملة للواجهة الرئيسية وتجربة التدريب.
- زر «شرح الموقع» بتجربة Modal وحركة خفيفة.
- Lazy Loading للصور + Preloading للسؤال التالي.
- استخدام WebP للصور النقطية مع الاحتفاظ بـ SVG حيث يناسب.
- منع Layout Shift عبر حاويات ذات Aspect Ratio.
- React.lazy لتقسيم تحميل الصفحات.
- نظام Question Media وDiagram جاهز لـ SVG/Image/Interactive.
- لوحة إدارة جديدة: نظرة عامة، الطلاب، الأسئلة، الصور.
- محرر أسئلة CRUD من لوحة الإدارة.
- رفع الصور من الإدارة مع ضغط PNG/JPG إلى WebP قبل الإرسال.
- تسجيل نتائج الاختبارات وعرض مؤشرات الأداء.

## التشغيل
```bash
npm install
npm run dev
```

## الإنتاج
```bash
npm run build
```

اضبط `VITE_API_URL` على رابط الـBackend الحقيقي قبل البناء إذا كانت الواجهة والـAPI على خدمتين منفصلتين.

> ملف `_headers` مخصص لمنصات مثل Netlify/Cloudflare Pages التي تدعم قواعد headers بهذا الشكل. إذا كانت منصة الاستضافة لا تستخدمه، طبّق Cache-Control نفسه من إعدادات CDN/الاستضافة.
